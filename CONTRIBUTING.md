# Contributing to SpanDraft

Thanks for your interest in SpanDraft!

At this stage, the best way to contribute to the project is by reporting bugs, suggesting improvements, and sharing ideas through GitHub Issues.

## Reporting bugs

When reporting a bug, please include:

- what you expected to happen
- what actually happened
- steps to reproduce the problem
- your operating system, if relevant
- screenshots or error messages, if available

## Suggesting features and improvements

Feature requests and ideas are welcome.

Please describe:

- the problem or use case
- what you would like SpanDraft to do
- why the proposed change would be useful

Before opening a new Issue, please check whether a similar one already exists.

## Code contributions

SpanDraft is currently not accepting unsolicited code contributions.

This may change as the project develops.
