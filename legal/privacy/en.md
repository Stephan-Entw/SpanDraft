Last updated: November 1, 2026

## 2. General

SpanDraft is a locally run desktop application for beam calculations. No registration or user account is required to use the application.

SpanDraft does not include telemetry, analytics, or automatic crash reporting. Project files, calculation data, settings, and information entered by the user are not transmitted to the provider or to third parties.

The normal functions of SpanDraft do not require an internet connection.

## 3. Data Processed and Stored Locally

SpanDraft processes data exclusively on the user's device.

This may include, in particular:

- project and calculation data,
- project information such as title, reference, and “Created by”,
- application settings,
- recently used projects and recovery data,
- custom materials and cross-sections.

Project files and exported PDF reports are stored in a location selected by the user. Settings, recovery data, and local libraries are stored in the local application data area of the user's Windows account.

The “Created by” information is optional. For a new project, SpanDraft may suggest the name last used when creating a project or, on Windows, the name of the Windows user account. This suggestion can be changed or completely deleted before use. The information is processed locally and, where applicable, stored in the project file and used in the calculation report.

## 4. Modification and Deletion

Project information can be modified in SpanDraft. Project files and exported reports can be deleted by the user through the file system.

Locally stored settings, recovery data, and custom libraries remain exclusively on the user's device and can also be removed there.

## 5. External Storage Locations and Links

SpanDraft does not provide its own cloud synchronization.

If a user saves files to a network drive, cloud folder, or another externally synchronized storage location, any resulting data transfer is performed by the respective storage or synchronization service and not by SpanDraft.

External links, for example to the SpanDraft GitHub project, are opened in the browser only following an action by the user. The privacy policy of the respective provider applies to the website subsequently visited.
